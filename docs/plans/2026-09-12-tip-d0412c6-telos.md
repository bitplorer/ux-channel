## 1. TELOS + ponytail

A layer's **telos** is the end it exists to serve. Callers **USE** that
end. Re-implementing it elsewhere is bloat even when the clone is thin.

| Layer | Telos (owns) | Must not own |
|-------|--------------|--------------|
| **ux-dom** | Tree → HTML (`__render__` / `to_html_bytes`), `Document`, `extract_by_id`, `ux_dom.response` | Intent / Cap / Result ops, product CLI |
| **ux-behavior** | Product meaning → verified `list[Op]`; MorphState / `@action` | Raw HTML, wire codecs, Cap crypto |
| **ux-channel** (this repo) | Intent → Cap → Result; wire; Cap Host (cek-runtime); `StateStore`; Cap HTTP `mount_channel` / `Channel.boot` | HTML trees, CSS, Document serialize, product `uxcompose` / Clock A |
| **ux-motion** | Presence / transition plans as data (IR v1) | `@action`, Document construction, Cap mint |
| **cek-host** | Cap mint / verify / project (authority) | HTTP Product host (Clock A) |
| **cek-surface** | Surface / Peer IR / carriers | A second Cap machine on Channel |
| **ux-compose** | Author composition + `uxcompose` + Clock A + Isolation `wire/` | Re-implementing any specialist |
| **FastAPI / Starlette** | HTTP process | Channel protocol, Document serialize |

**Ponytail** (shrink only in this order — never reverse):

1. **YAGNI** — delete the unused plane if no locked L depends on it.
2. **Reuse the owner** — call ux-dom / cek-host / stdlib.
3. **stdlib** — `html.escape` only when the owner is absent.
4. **Minimum local** — leftover-teach + prefer-owner; do not gut KEEP doors.

Organize by **capability / happy path**, not by `cli/` or `services/`.
One taught path per job.

**Intent Vector** (required on every DO Soft; none in this queue):

| Field | Meaning |
|-------|---------|
| **Intent** | One capability end (the telos being served) |
| **Vector** | Owner library → channel USE site (`path:line`) |
| **Concern** | One Soft; prefer reuse-owner / fail-closed / leftover-teach |
| **Not** | Folder move, public rename, encyclopedia, sixth product, E14 |
