# @ux-channel/media-livekit

Thin helper around **livekit-client** (peer dependency).

- **Does not** implement WebRTC signaling in Python.
- **Does not** register as a `ux-bridge` widget.
- Tokens from Python: `ch.media.plugin(room, sub=user, mode="sfu")`.

```bash
npm i livekit-client @ux-channel/media-livekit
```
