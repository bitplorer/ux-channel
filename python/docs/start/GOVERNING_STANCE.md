# Governing stance

## Frozen (principles + core)

- **I/O channel, not driver** — authorize + record; adapters own buses ([IO_CHANNEL.md](../workplace/IO_CHANNEL.md))
- Mesh membership ≠ trust (scopes + tickets; attenuate only)
- **Workplace** = product façade for policy-shaped rooms ([WORKPLACE.md](../workplace/WORKPLACE.md))

- Intent → Action → Result (one mutation door)
- Stable uid for live workplaces
- **Quantity ≠ session chrome** (`Quantity.from_store` + refuse helpers)
- Host markup ⊥ control plane ⊥ bridges
- Caps attenuate; audit when enabled
- **AX** = `agents(ch)` only
- **Foundations** = organic modules (`quantity`, `attenuate`, `morph_ir`, …)

## Opt-in shell (safe defaults when used)

- `ChannelConfig.regions="app.regions"` — file discover
- `uxchannel region add|list|check|recipes`
- `agents.tools_for(region=, role=)` / `explain` / `history`
- `ch.inspect` — read-only; prod off by default

## Escape hatches

- Hand-mounted `Region` / `@ch.on` without file tree
- Explicit `uid =` freeze; short `@Region.action(name=...)`
- `ax=False`, `__region__ = False` on mixins
- `strict_action_names=False` (discouraged)
- `inspect_enabled=False`
