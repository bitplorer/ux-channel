# Channel components — uxchannel 0.1

Optional widgets under `ux_channel.components` (Counter, Flash, forms, …).

- Named **ChannelComponent** (not `Component`) to avoid ux-dom clashes  
- They use regions + actions under the hood  
- Prefer plain `@ch.region` + `@ch.on` when learning  

See package `ux_channel.components` and examples under `examples/components_demo/`.
